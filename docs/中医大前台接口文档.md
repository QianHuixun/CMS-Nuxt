# 中医大前台接口文档

> 版本：接口定义版  
> 用途：前台 Ajax 联调、Nuxt 服务端接口实现、mock 数据准备  
> 依据：原 Word 草案二次整理，并结合当前仓库 `chunyu-cms-web` 的 Nuxt 服务端结构、后台业务模块和现有数据表规划。

## 一、当前项目对齐说明

当前 `chunyu-cms-web/app/pages` 仍以原视频站页面为主，尚未落地中医大前台展示页，因此本文档按拟建设的中医大前台页面来定义接口。

服务端实现建议：

- 正式接口放在 `chunyu-cms-web/server/api/v1` 下，对外路径为 `/api/v1/...`。
- 前台展示接口全部只读，均使用 `GET`。
- 不需要登录鉴权，不读取或下发 `Authorization`。
- 不包含新增、编辑、删除、统计写入接口。
- 本阶段不提供知识图谱接口、节点数据和边数据。
- 路径保留草案里的 camelCase，如 `/softwarePatents`、`/wordClouds`；mock routes 可同时提供 kebab-case 别名。
- 人才详情不返回手机号等个人联系方式。
- 论文详情和统计不返回引用次数、阅读热度。

现有项目数据来源建议：

| 前台模块 | 前台接口 | 当前项目可映射数据 |
| --- | --- | --- |
| 核心资源库 | `/databases`、`/tools` | 后续 `resource_navigation` 可增加资源类型区分，或拆成数据库/工具配置 |
| 人才展示 | `/talents`、`/talents/{id}` | `talent`、`talent_paper`、`talent_topic`、`talent_patent` |
| 课题 | `/projects/*` | 当前 `topic` 表，前台统一命名为 project |
| 专著 | `/books/*` | 当前 `pa_book` 表 |
| 活动 | `/activities/*`、`/activityPhotos/*` | 当前 `activity` 表，剪影可由活动图片/封面扩展 |
| 论文 | `/papers/*` | 数据规划中的 `paper` 表，当前 schema 尚未落地 |
| 软著专利 | `/softwarePatents/*` | 数据规划中的 `patent` 表，软著可与专利统一为成果表或用 type 区分 |
| 词云 | `/wordClouds` | 数据规划中的 `paper_keyword`，或独立词云配置表 |

## 二、统一约定

### 2.1 Base URL

```text
/api/v1
```

### 2.2 统一响应结构

成功：

```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

失败：

```json
{
  "code": 404,
  "message": "resource not found",
  "data": null
}
```

### 2.3 时间格式

| 项目 | 约定 |
| --- | --- |
| 时区 | UTC，后端统一返回 UTC，前端自行转换为本地时间 |
| 格式 | ISO 8601 字符串，例如 `2026-04-30T08:00:00Z` |
| 日期筛选 | `year` 使用 integer，例如 `2026` |

### 2.4 分页结构

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `pageNum` | integer | 页码，默认 `1` |
| `pageSize` | integer | 每页条数，默认 `10`；活动剪影默认 `12` |
| `total` | integer | 符合条件的总记录数 |
| `rows` | array | 当前页数据 |

分页响应：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "total": 0,
    "pageNum": 1,
    "pageSize": 10,
    "rows": []
  }
}
```

非分页列表响应：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "total": 0,
    "list": []
  }
}
```

## 四、接口详情

### 4.1 获取数据库列表

`GET /api/v1/databases`

说明：获取核心资源库页面的数据库入口，全量返回，不分页。

请求参数：无。

响应 `data.list[]`：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | 数据库 ID |
| `title` | string | 数据库名称 |
| `status` | string | `active` / `inactive` |
| `info` | string | 简介 |
| `url` | string | 访问地址 |
| `icon` | string | 前端图标标识 |
| `sort` | integer | 排序号 |

示例：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "total": 1,
    "list": [
      {
        "id": "db_tianhui",
        "title": "天回医简数据库",
        "status": "active",
        "info": "汇聚天回汉墓出土医简高清图像、释文、注释、单字切分图像与检索数据。",
        "url": "https://example.edu/databases/tianhui",
        "icon": "database",
        "sort": 1
      }
    ]
  }
}
```

### 4.5 查询课题概要列表

`GET /api/v1/projects/paginate`

说明：分页查询课题概要列表，支持年度和类型筛选。当前项目后台表名为 `topic`，前台统一命名为 `project`。

请求参数：

| --- | --- | --- | --- |
| `pageNum` | integer | 否 | 默认 `1` |
| `pageSize` | integer | 否 | 默认 `10` |
| `year` | integer | 否 | 年度筛选，可匹配立项年份或开始年份 |
| `type` | string | 否 | 课题类型：`国家级` / `省部级` / `厅局级` |

响应 `data.rows[]`：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | 课题 ID |
| `title` | string | 课题名称 |
| `type` | string | 课题类型 |
| `projectNo` | string | 课题编号 |
| `year` | integer | 立项年份 |

| `leaderId` | integer | 负责人 ID，可为空 |
| `institution` | string | 承担单位 |
| `coverImage` | string | 封面图 |
| `summary` | string | 摘要 |
| `progress` | string | 进度或状态 |

字段映射建议：

| 前台字段 | 当前表字段 |
| --- | --- |

## 五、推荐 mock 数据最小集

为支持前台首轮联调，建议 mock 至少准备：

| 模块 | 条数 | 说明 |
| --- | --- | --- |
| 数据库 | 3 | 覆盖 active/inactive |
| 自研工具 | 3 | 覆盖外部链接和内部链接 |
| 人才 | 6 | 至少 1 人关联论文、专著、课题、专利 |
| 词云 | 1 | 至少 20 个词 |
| 课题 | 12 | 覆盖 2 个年份、2 个类型 |
| 论文 | 12 | 覆盖 2 个年份、2 个类型 |
| 专著 | 8 | 覆盖有附件/无附件 |
| 软著专利 | 8 | software 与 patent 各半 |
| 活动 | 10 | active 与 past 均有 |
| 活动剪影 | 12 | 用于默认首屏瀑布/网格 |

## 六、待确认事项

| 事项 | 当前处理 |
| --- | --- |
| 路径命名 | 正式接口保留 camelCase；mock 额外提供 kebab-case 兼容别名 |
| 课题命名 | 前台使用 `projects`，当前后台/表结构可由 `topic` 映射 |
| 活动剪影 | 保留 `/activityPhotos/paginate`；若未建图库表，可先从活动内容图片生成 mock |
| 资源库数据 | 当前项目尚未落 `resource_navigation` schema，建议实现时加 `resourceType: database/tool` |
| 公开联系方式 | 人才前台接口不返回手机号；邮箱如需展示需产品单独确认，默认不返回 |
| 论文热度 | 论文统计和详情不返回引用次数、阅读热度 |
| 知识图谱 | 本阶段不设计任何知识图谱接口 |
