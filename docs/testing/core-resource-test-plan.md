# 核心资源库管理测试计划

## 功能范围

- 核心资源库管理菜单
- 数据库管理
- 自研工具管理
- 数据库资源分页列表
- 数据库资源新增、编辑、删除
- 数据库资源名称/状态筛选
- 数据库资源排序维护
- 数据库资源背景图 `coverUrl` 上传和回显
- 自研工具分页列表
- 自研工具新增、编辑、删除
- 自研工具名称/状态筛选
- 自研工具排序维护
- 前台只读接口 `GET /api/v1/databases`
- 前台只读接口 `GET /api/v1/tools`

## 不在本期范围

- 不做前台页面开发
- 不做真实外部系统连通校验
- 不校验 URL 是否可访问
- 不做复杂图标库管理
- 不处理旧“资源导航管理”菜单

## 测试范围

- 后台数据库管理 CRUD
- 后台自研工具管理 CRUD
- 菜单显示
- migration 幂等
- 前台只读接口只返回 `active` 且 `del_flag = '0'` 数据
- 4.1 人才管理回归
- 5.1 数据导入回归
- 5.2 书籍仿真录入回归
- 6.1 词云回归
- 6.2 图表生成回归
- 活动管理回归

| 编号 | 测试项 | 预期结果 |
| --- | --- | --- |

| CR-DB-008 | 上传并回显 `coverUrl` | 复用图片上传，保存后可在列表和编辑弹窗回显 |
