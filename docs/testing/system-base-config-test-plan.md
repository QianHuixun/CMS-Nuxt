# 系统基础配置管理测试计划

- 导航配置
- 导航入口新增、编辑、删除

- 导航入口排序维护
- 导航入口最多 3 个 `active`
- 前台只读接口 `GET /api/v1/navigation`
- 屏保配置
- 屏保图片新增、编辑、删除
- 屏保视频新增、编辑、删除

- `triggerSeconds` 保存
- 屏保名称/媒体类型/状态筛选
- 前台只读接口 `GET /api/v1/screensaver`
